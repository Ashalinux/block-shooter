# Block Shooter

**A first-person 3D shooter that runs right in your browser – one HTML file, no install.**

<br />

## Features

- First-person controls with mouse look (pointer lock)
- Weapons with ammo and reloading
- Animated 3D soldier model (glTF)
- Runs in any modern browser – no build step

<br />

## Play

Because the game loads a 3D model, open it through a small local web server:

```bash
npx serve .
```

Then open the shown address in your browser and click into the game to start.

**Controls:** `WASD` to move · mouse to aim · click to shoot · `R` to reload
